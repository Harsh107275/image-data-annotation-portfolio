# Project 1: Traffic Object Annotation Using CVAT

## Project Overview
This project demonstrates practical image annotation using CVAT (Computer Vision Annotation Tool). The task involves identifying and drawing bounding boxes around objects in a busy Indian city traffic scene.

## Objective
To practice object detection annotation by identifying road users and relevant objects in a real-world traffic image.

## Tool Used
- CVAT — Computer Vision Annotation Tool

## Objects Annotated
- Person
- Bus
- Car
- Motorcycle
- Mobile phone shop and other visible objects, where applicable

## Annotation Method
- Identified objects visible in the image.
- Drew rectangular bounding boxes around selected objects.
- Assigned labels to annotated regions.
- Reviewed the annotations in the CVAT interface.

## Skills Demonstrated
- Image annotation
- Object identification and classification
- Bounding-box annotation
- Label assignment
- Attention to detail
- Basic annotation quality checking
