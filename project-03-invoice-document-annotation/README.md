# Project 03: Invoice Document Annotation using CVAT

## Project Overview
This project demonstrates document text annotation using CVAT (Computer Vision Annotation Tool). The task involves identifying and annotating text regions in a business invoice.

## Objective
To practice document annotation by identifying important text elements in an invoice, including:
- Company name and contact information
- Invoice number and invoice date
- Billing information
- Item descriptions and quantities
- Prices, taxes, and total payable amount

## Tool Used
- CVAT — Computer Vision Annotation Tool

## Annotation Evidence
A screenshot captured from the CVAT annotation interface is included in this repository as visual evidence of the project.

The screenshot shows text-region annotations on a sample business invoice, with 36 items displayed in the CVAT interface.

## Skills Demonstrated
- Document image annotation
- Text-region identification
- Invoice field recognition
- Attention to detail
- Working with an annotation tool

## Project Limitations
This repository contains a screenshot of the annotation interface only. The original image dataset and exported annotation files (JSON/ZIP) are not included.

## Portfolio Note
This project is intended to demonstrate practical familiarity with CVAT and document annotation workflows. The screenshot represents the visible annotation work performed in the tool.
